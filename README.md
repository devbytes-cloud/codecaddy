# CodeCaddy
> Local-first snippet storage for engineers who actually ship.

[![Website](https://img.shields.io/badge/website-codecaddy.dev-blue)](https://codecaddy.dev)
[![Discussions](https://img.shields.io/github/discussions/devbytes-cloud/codecaddy)](https://github.com/devbytes-cloud/codecaddy/discussions)

CodeCaddy is a snippet manager built for platform engineers, SREs, and infrastructure developers. Save every kubectl incantation, Helm chart fragment, and Terraform snippet without losing them to scrollback or notes apps.

**[→ Try CodeCaddy (free)](https://codecaddy.dev)**

## What's in this repo

This is the community space for CodeCaddy. The source code for CodeCaddy itself is closed, but this repo is where:

- **Bugs are tracked** → [Issues](https://github.com/devbytes-cloud/codecaddy/issues)
- **Questions are answered** → [Discussions › Q&A](https://github.com/devbytes-cloud/codecaddy/discussions/categories/q-a)
- **Features are discussed** → [Discussions › Ideas](https://github.com/devbytes-cloud/codecaddy/discussions/categories/ideas)
- **Releases are announced** → [Discussions › Announcements](https://github.com/devbytes-cloud/codecaddy/discussions/categories/announcements)
- **Documentation lives** → [docs/](docs/)
